# Evidence — `EVID-NNN`

Evidence is the thing the whole thesis centers on, so it gets its own object. When you take the
conscience's best advice — *"a 15-minute call with the right person beats `/canvas`"* — and go do the
call, the result lands **here**, as one file per signal, instead of evaporating into memory.

Run **`/evidence`** to capture one (paste your notes or describe what happened; BOSS drafts the file with
an honest grade). Run **`/interview`** to prep a call and debrief it straight into evidence.

## The 3-grade ladder (fixed — resist growing it)

The grade is the load-bearing field. Three rungs, blunt on purpose:

| Grade | Means | Weight |
|---|---|---|
| `stated-pain` | Someone **said** it hurts. | Weakest — the Mom Test warns talk is nearly free. |
| `observed-behavior` | You **watched** them struggle, use a workaround, or bounce. | Middle — behavior beats opinion. |
| `commitment` | They gave up something real: **time, money, reputation, a calendar slot.** | Strongest — the only grade that costs the other person something. |

Grade honestly. *"I'd totally use this"* is `stated-pain`, not `commitment` — a compliment is not a
receipt. BOSS will push back on grade inflation when it drafts a file.

## Frontmatter schema

```markdown
---
id: EVID-NNN
type: evidence
owner: "@you"
status: active            # active | superseded
date: YYYY-MM-DD
source: <who / where>      # a person, a session, a metric — where the signal came from
method: interview          # interview | observation | pretotype | metric | commitment-test
grade: stated-pain         # stated-pain | observed-behavior | commitment
assumption: <which canvas riskiest assumption this bears on, in a phrase>
---

# EVID-NNN — <one-line summary of the signal>

<≤10 lines. What actually happened, in plain words. No spin, no rounding up.>
```

## What this is not

- **Not a score.** Counts and grades are facts shown once in context — never a gamified meter, never a
  "validation level 3/10!" A dashboard of shame is the opposite of the point.
- **Not a CRM.** No contacts, no pipeline, no scheduling. One signal, one file.
- The conscience reads this ledger (counts + the most recent one) so its nudges get specific — and goes
  **quieter** when real commitments exist. Evidence is how the conscience earns silence.
