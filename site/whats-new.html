What's new

Every release, in the open.

BOSS is built in public and moves fast. This page is generated from registry/CHANGELOG.md — the same file boss sync reads when it tells a project what's changed since its pinned version. One source, two audiences.

Inside a project: boss status shows your pin against what's installed, and /boss-sync brings you forward as a reviewed, narrated diff — never a silent update.

make it real.
$npx bossbuild new my-app

Source on GitHub · npm · MIT licensed · zero dependencies · no account.

Every byte stays on your machine. The only network call BOSS makes is when you type boss update — a GET to the public npm registry asking for a version number. Nothing is sent about you, your code, or your ideas. No analytics, no telemetry, no phone-home; the check never runs unless you ask for it.

Where this actually is: v0.165.0, built in the open and used daily by its author. Very few other people have used it yet. BOSS is its own first project — it runs its own modes, files its own ideas, and its conscience nudges the person building it.
