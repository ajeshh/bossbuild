Credits

Almost none of this is original.

BOSS is mostly a distillation of other people's published thinking, arranged so it arrives at the moment a founder needs it. That's the honest description of the product, and it means the people below are load-bearing rather than decorative. 41 named sources sit behind the practice shelf.

The one-line note beside a name is what BOSS took from them — a study pointer, not their endorsement and not their verbatim view. No agent in BOSS impersonates a person; mentors are archetypes that cite the practice, never someone's name.

▸citation debt

39 of these still have no link, and that's a bug

Every practice BOSS ships records who a claim came from. Far fewer record where. That gap is real and it's ours: the verification work was done — BOSS's /vet pass goes to the primary source before it grades anything — and then the URL was thrown away.

An attribution without a URL is half a citation. It can't be re-checked when the practice comes up for review, the person can't be credited properly, and the next reader has to redo a search someone already did.

So the rule now sits inside /vet itself: write down the URL you actually opened — not the thread that pointed at it. Sources are stored in one registry, and each name here becomes a link the moment its URL is filled in. Currently 2 linked, 39 outstanding.

make it real.
$npx bossbuild new my-app

Source on GitHub · npm · MIT licensed · zero dependencies · no account.

Every byte stays on your machine. The only network call BOSS makes is when you type boss update — a GET to the public npm registry asking for a version number. Nothing is sent about you, your code, or your ideas. No analytics, no telemetry, no phone-home; the check never runs unless you ask for it.

Where this actually is: v0.175.0, built in the open and used daily by its author. Very few other people have used it yet. BOSS is its own first project — it runs its own modes, files its own ideas, and its conscience nudges the person building it.
