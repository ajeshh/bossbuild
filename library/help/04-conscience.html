This is the part people either value or want to switch off, so it is worth being precise about what it does, what it cannot do, and every way to shut it up.

Detection is mechanical. Tact is the model's job.

A lightweight hook watches the state of the work — how many ideas are captured, how many were tested, whether a spec traces to anything the canvas validated. When a named moment's condition is met, it fires. No model is ever asked “is this person drifting?”

Only once a moment is earned does a model compose the actual words. So the judgment about whether to speak is deterministic and inspectable; only the phrasing is generated. That split is the entire design — a model deciding when to interrupt you would interrupt you constantly, because interrupting is the only way it can demonstrate value.

It speaks once, then stops

A moment fires, says its piece, and goes quiet. It does not block your prompt, does not repeat itself, does not grade you, and it will point at something better than its own features — a fifteen-minute call with the right person beats another pass at any BOSS artifact, and it will say so.

Its only positive signal is silence. If it is not speaking, nothing it watches is out of shape. That is worth knowing, because a tool that is quiet can look like a tool that is broken.

Turning it down

  • boss conscience pause --for 8h — silence everything for a bounded sprint. It comes back on its own, because a permanent off switch you set once during a bad afternoon is not a choice you get to revisit.
  • boss conscience mute <moment> — turn down one nudge while the rest keep speaking. unmute brings it back.
  • boss conscience activity — how often it has actually fired. Run this if it feels noisy; the answer is usually lower than the feeling, and if it isn't, that is a bug worth reporting.

It never blocks, and it never has the last word. You are the one deciding.
