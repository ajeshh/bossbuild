# Source — drop anything here

This folder is the inbox for material you already have: a deck, a market report, a regulator's
figures, a survey export, a page you saved, a transcript, three paragraphs of notes. Copy it in;
nothing else is required.

- **One flat folder.** Don't sort by topic — deciding whether a document is *market* or
  *competition* is the work `/import` does for you, and it does it better after reading the file.
- **Date the name** when the date matters: `2026-09-13-deck-v3.pdf`. A number from March is not a
  fact about today, and the playbook shows the date next to the file.
- **Nothing here is a record.** A file in this folder is raw material. It becomes part of the
  venture only when a record holds it — the canvas, a persona, the competition table, a graded
  piece of evidence — and BOSS writes those only when you say yes.

`/import <file or url>` snapshots a document here and folds what it says into your idea. Running it
on a file that is already in this folder is the way to have it read into the records. `boss
playbook` lists what's here under **Market → Research you've imported**, by name and date.
