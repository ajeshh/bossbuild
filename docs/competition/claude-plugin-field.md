# The Claude Code plugin field — who is solving BOSS's problem *as a plugin*

> **How this was read, so the gaps are legible.** Two marketplace manifests: **official, 295
> plugins**; **community, 2,282 plugins**. Every entry's name + description was scanned by keyword
> (founder · startup · idea-to · PRD · product discovery · MVP · vibe · mentor · memory · decision ·
> conscience · drift). Matches were shortlisted; the shortlist's repos were opened for stars,
> licence, dates and README. **Anything whose description did not use those words was not seen.**
> That is a real hole — a rival calling itself a "harness" or an "operating system" with no
> founder vocabulary would slip through — and it is named here rather than papered over.

## The shape of the field, in one paragraph

**The founder-shaped niche exists in the marketplace, and nobody has stuck in it.** Every plugin
whose description says *founder*, *startup idea*, or *co-founder* is tiny — **0 to 33 stars** —
and several were created and abandoned on the same day. The one with the most ambition, haytham,
retired itself in July. Meanwhile the *craft* niche next door is dominated by a single 285k-star
plugin (superpowers, filed separately). Read together: many people have had BOSS's idea; the ones
who shipped it as a plugin shipped a one-shot pipeline, got no traction, and left. **Whether that
is because the idea is wrong or because a one-shot plugin is the wrong shape for it is exactly the
question BOSS's n=0 cannot yet answer either.**

## What this field says, read together

1. **The founder plugin is a graveyard of one-shot pipelines.** Idea → research → verdict → spec, in
   one command, then nothing. Every abandoned one has that shape. BOSS's bet — that the value is in
   *staying*: modes, re-entry, an evidence ledger that changes what the conscience says — is
   precisely the shape none of them tried. That is either the gap or the reason they left.
2. **The two alive ones each hold one thing BOSS should study.** product-discovery's typed evidence
   with a *synthetic* rung and a per-session validation pass; arness's three ceremony tiers. Neither
   has the other, and neither has a build half or a mentor board.
3. **Distribution is the solved problem next door.** superpowers shows what one repo on fourteen
   hosts with a `SessionStart` hook looks like. BOSS's plugin (v0.302.0) is deliberately thinner —
   the front door, not the body — and that is a bet against superpowers' shape, not an oversight.
   Recheck in 90 days whether the thin door converts.
4. **Naming.** `boss-ai-agent` exists and does the one thing BOSS refuses. When the `boss` plugin is
   submitted to `claude-community`, the description has to say what BOSS is *not* in the first line.

## What I did not find

- The **2,282 − shortlist**: everything whose description used none of the keywords. A rival
  described as a "harness", "control plane", "operating system" or "pipeline" without founder
  vocabulary was not seen.
- **Install counts.** Neither marketplace publishes them; stars are the only public signal, and
  the official marketplace's own repo (★36k) is the star count for *the directory*, not any plugin.
- **Cursor's, Codex's and Gemini's marketplaces.** superpowers is in OpenAI's; BOSS's field there is
  unread. IDEA-006 territory.
- **Cowork-only plugins** (`cowork-plugin-management` and kin) — a different host surface, skipped.
