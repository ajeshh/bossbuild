# RVW-058 — emerging AI-specific patterns + the FTC click-to-cancel rule (under-sourced / unverified)

## The claim
- **Source:** `/humane-refresh` first sweep, pass 1 — the *open items* the verifier flagged. See
  [SESSION-2026-06-21-humane-refresh.md](../sessions/SESSION-2026-06-21-humane-refresh.md).
- **Core assertion:** the catalog should add the most-current AI-era patterns — **token-cost / usage-billing
  surprise**, **AI-washing**, **synthetic social proof / deepfake testimonials**, **manipulative
  personalization**, AR/VR/voice patterns — and the **FTC "click-to-cancel" / amended Negative Option Rule**
  specifics.
- **Inbox file:** n/a (research-sourced).

## Verdict: NOT-YET
This is the honest outcome, and it's *itself* a finding: the patterns most native to BOSS's audience
(token-cost surprise billing, AI-washing, synthetic/deepfake social proof) are **emerging precisely because
the literature hasn't caught up** — they live in blog posts and news, not yet in peer-reviewed or regulatory
sources the verifier would pass. Adopting them now means importing unverified definitions into a catalog
whose entire worth is accuracy. Hold. The watchlist will re-sweep; this flips to ADOPT when real sourcing
exists.

## If REJECT / NOT-YET
- **Why not:** evidence grade (rubric #2). Zero of these reached adversarial verification; the click-to-cancel
  specifics were actively refuted.
- **Re-open conditions (per cluster):**
  - **AI-washing** — closest to ready: the FTC's Sept-2024 "Operation AI Comply" is a real, citable
    enforcement hook. Re-open on a targeted sweep that pins the FTC actions + any peer-reviewed definition.
  - **Token-cost / usage-billing surprise** — re-open when a named taxonomy or a regulator/consumer-body
    report defines it (not just vendor/blog commentary).
  - **Synthetic social proof / deepfake testimonials** — re-open on FTC's fake-reviews rule text or a
    peer-reviewed naming (note: *fabricated* social proof is partly covered already via CDT "fake social
    proof" + RVW-056's manufactured-scarcity family; the *deepfake-specific* variant is what's NOT-YET).
  - **FTC click-to-cancel / Negative Option Rule** — re-open with a fresh, carefully-sourced read of the
    final rule text **and** its current legal status post-2024/25 litigation. Do not state its contents until
    then.
