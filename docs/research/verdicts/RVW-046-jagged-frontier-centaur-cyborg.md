# RVW-046 — the jagged frontier: centaur/cyborg, and re-ask per model

## The claim
- **Source:** Dell'Acqua, Mollick et al., *Navigating the Jagged Technological Frontier* (Org Science 2025; 758 BCG consultants) — inside the AI-suitable frontier: +12.2% tasks, ~25% faster, higher quality; **outside it: ~19pp less likely to be correct.** Gives the centaur-vs-cyborg model; the frontier moves with each model.
- **Core assertion:** AI helps sharply on some tasks and *hurts* on others (the "jagged frontier"); a founder must judge which side a task is on — and re-judge with each new model.
