# RVW-135 — contribution needs rituals (office hours, credits, crits), not just a process

## The claim
- **Source:** a design lead's essay on contribution rituals, 2026-04.
- **Core assertion:** Contribution doesn't speed a system up; its payoff is advocacy. Rituals beat process: keep weekly office hours and never cancel them, credit contributors in the docs (with an opt-out), run crits and hackathons. Don't start too early: the signal is when several teams describe the same missing pattern. AI tools now ship system-adjacent components that skip contribution entirely, so human review matters more.
- **Inbox file:** `~/Projects/inbox/bossbuild/The design system contribution habits…pdf`
