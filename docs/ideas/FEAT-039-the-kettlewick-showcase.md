# The Kettlewick showcase

IDEA-110, promoted the day its trigger fired. Ajesh's additions (2026-09-13) shape it: rename
(Tidewell is real), fill every slot, a folders page, the shipped files as examples, and a standing
rule for keeping it current.

## Goal
`oyeboss.build/demo/` shows BOSS run on one venture from the first `boss new` to a deck a founder
could hand to a room — every page produced by the same code an install produces, from records a
reader can open. Fictional, and says so on every page.

## Acceptance criteria
- [x] `demo/kettlewick/` holds the record set; `node scripts/gen-demo.js` writes `site/demo/`
      {index, playbook, design, board, folders, inside}.html with no external request.
- [x] `boss playbook --questions` on the rendered demo reports **0 open** (the design-lane holes
      excepted until their records land, listed by name in `check:demo`).

- [x] `folders.html` lists every directory of the temp project with a line; `inside.html` carries
      the four shipped files verbatim (a test diffs one against `stages/`).
- [x] `web/demo.html` builds; NAV has *Demo*; `check:site` passes; `check:demo` is in `npm run
      check` and fails on a manufactured hole (a test).
- [x] CHANGELOG bullet; IDEA-110 promoted.

## What "wrong" looks like
- A page prettier than what `boss` produces — a hand-written slide, a typed tree.
- A real person's name, photo or quote anywhere in `demo/`.
- A hole on the demo that nobody noticed — the gate exists to make that impossible.
- A reader who can't tell it's fictional.

## Paths that must not break
- **Destructive path:** `gen-demo` writes only under `site/demo/` and a temp dir; never `demo/`.
- **Negative path:** nothing in `demo/` is anyone's private data — it is authored fiction, tracked.

## Flow
`npm run gen:site` → `gen-demo` → `site/demo/*` → `npm run check` (`check:demo`) → deploy with
the site. A founder-facing flow: none — this is BOSS's own surface.

## Smoke check
- `node scripts/gen-demo.js` exit 0; `ls site/demo` = 6 files; `grep -c fictional site/demo/*.html`
  ≥ 1 each; `npm run check` at baseline.

## Validated learning
- **Learning hypothesis:** a stranger who reaches the demo installs more often than one who reads
  the guide (EVID-002 said the value wasn't being seen).
- **What result would change the plan:** the demo pages are opened and the deck isn't (drop the
  deck from the entry page) or nobody reaches `/demo` (reposition — IDEA-109).

## Out of scope

  to the renderers to make the demo look better.
