## The frame

> The first 10% — the polished prototype — is now free. BOSS is the layer for the 90% that decides
> whether it's a **real business**, not a pseudo app.

It restates the PRINCIPLES.md "why" (pseudo app vs. real-business-value app) in a sharper, more
quotable shape, with an outside credibility anchor (Schoening / Notion). The "free 10%" maps cleanly
onto what code-gen tools (Lovable/v0/Bolt) already own; the "90%" maps onto BOSS's complementary
thinking layer (the v0.24 positioning line).

## The open question (is it worthy?)

Worthy = it sharpens positioning **without** becoming a slogan BOSS has to live up to or a new surface.
Tests before it earns a place:
- Does it say something the current v0.24 line ("the just-in-time conscience for AI-native founders —
  pause it any time") doesn't already carry? Or does it *duplicate the duplicate*?
- Does "10% / 90%" survive a `mentor-pitch` read, or does it sound like a stat BOSS can't back (the
  number is Schoening's framing, not BOSS's data — RVW-027 graded the source as experiential, n≈1)?
- Does it serve the sharp-fit cohort (vibe-virtuoso / eng-builder / returning-founder) or read as
  marketing-speak to them? Quick persona react before anything ships.

## Smallest worthy slice (if it passes)

A single positioning candidate line handed to `mentor-pitch` / CANVAS §Promises — **not** a skill,
hook, or conscience moment. If it doesn't beat the existing line head-to-head, it stays here as a
recorded "considered, didn't earn it."

## Gate (as written)

**Re-open trigger:** BOSS has a **reachable public surface** — a published package or a live URL —
and needs words on it. That is when a positioning frame stops being a phrase and starts being a
decision about what the page claims.

**What does NOT re-open it:** finding the line quotable. The frame is already written down here and
loses nothing by waiting; the thing it is gated on is a page, not a better sentence.
